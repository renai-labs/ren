# ren-v1 credential UX: parity list

Evidence for [`../owner-access.md`](../owner-access.md) section 13. Each row is a ren-v1 surface and its v2 place. v2 keeps the same UX. Paths are in `../ren-v1/packages/app/src/`.

## Surfaces

## Behaviour rules

The UX lessons in [`ren-v1.md`](ren-v1.md) ("Credential UX feedback", rows 1 to 15) apply as rules. Each v2 surface above follows them.
