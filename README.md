# Ren

Ren is a platform to build agent factories. Delegate your first task, then scale from a single chat into an autonomous factory your whole team runs on.

Ren is in beta.

## Get started

Create an account at [useren.ai](https://useren.ai), then follow the [quickstart](https://useren.ai/docs).

## Contributing

Ren does not accept outside contributions. Only collaborators can open pull requests and merge to `main`.

To report a bug or request a feature, [open an issue](https://github.com/renai-labs/ren/issues/new/choose).
