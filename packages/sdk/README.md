# @renai-labs/sdk

The public TypeScript SDK for Ren.

## What belongs here

- Re-exports of `@ren/client`.
- Auth, configuration and convenience helpers for SDK users.

## What does not

- Generated code (`@ren/client`).
- Imports from `core`, `db` or `server`.

## Dependencies

`@ren/client`.

## Commands

```sh
bun run test
bun typecheck
```
