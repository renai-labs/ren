# @ren/ui

React design system.

## What belongs here

- Primitives, composites, layout shells, icons and design tokens.

## What does not

- Data fetching or API calls (`@ren/app`).
- Product screens (`@ren/app`).

## Dependencies

`react` and `react-dom` as peers.

## Commands

```sh
bun run test
bun typecheck
```
