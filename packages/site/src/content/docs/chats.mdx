A chat is a conversation with Ren in a [space](/docs/spaces/). Ren uses the instructions, apps, repositories, drive and permissions of that space.

<Screenshot
  shot="chats/overview-split"

  caption="A chat with the side panel open."
/>

## Start a chat

<Steps>

1. Select **New Chat** in the sidebar.

2. Pick the space to chat in from **Working in** above the composer.

3. Type your request and press Enter.

</Steps>

A chat can also start from a [channel](/docs/channels/), an [automation](/docs/automations/) or a [task](/docs/tasks/).

**Chats** in the main sidebar and the [Inbox](/docs/inbox/) of a space list all your chats and that space's chats. Filter them by space, status, where they started or when they last changed.

## Chat visibility

Every member of a space can see its chats and send messages in them. Chats in your personal space are visible only to you. Admins see a space's chats only after they join it.

## Model

Select the model name in the composer to choose another model. For models that support it, the dropdown next to the model sets the reasoning effort. You can also press `⌘` + `'` or send `/model`.

A new model applies from your next message. If you do not pick one, Ren uses the [default model](/docs/model-providers/#pick-a-model). If a model is not available, Ren uses the next one in that order.

## Mentions

Type `@` in the composer, then pick a category and an item to mention it in that message.

<Screenshot
  shot="chats/mentions"
  alt="The mention menu below the composer with Tasks, Chats, Apps, Agents, Files and Repositories"
  caption="Type @ to open the mention menu."
/>

| Category     | What Ren gets                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------- |
| Tasks        | A link to the task.                                                                               |
| Chats        | The ID of the chat, so Ren can read it.                                                           |
| Apps         | Ren uses that app for the request. If the space can't use it yet, Ren shows a card to connect it. |
| Agents       | The name of the agent, so you can hand work to it.                                                |
| Files        | The path of the file on the computer of the chat or in the space drive.                           |
| Repositories | The repository to work in.                                                                        |

## Attach files

Select **+** in the composer, drag a file onto it, or paste it. A message can have up to 10 files, 100 MB each.

Ren reads images up to 20 MB, and PDFs and text files up to 10 MB, directly. It opens other files with its tools.

## Send while Ren works

You do not have to wait for Ren to finish. A message you send while Ren works waits above the composer until the current turn ends (queue). To make Ren read it now (steer), hover over it and select **Send now**.

<Screenshot
  shot="chats/send-now"
  alt="Two queued messages above the composer, with Send now on the first one"
  caption="Hover over a queued message to send it now."
/>

| Key      | What it does                 |
| -------- | ---------------------------- |
| Enter    | Queue the message            |
| `⌘Enter` | Steer the message            |
| `⌘↑`     | Edit the last queued message |
| Esc      | Stop Ren                     |
| `↑` `↓`  | Show your earlier messages   |

To make steer the default, open **Settings → Preferences** and set **Messages sent while Ren works** to **Steer the current turn**. Enter and `⌘Enter` then swap.

## Questions and permission requests

When Ren has a question or needs permission, it pauses and shows a card above the composer.

<Screenshot
  shot="chats/permission"
  alt="A permission card asking to run bun run db migrate --env staging, with Allow once, Always allow and Deny"
  caption="A permission request."
/>

- **Question:** select an answer or type your own, then select **Continue**.
- **Permission request:** select **Allow once**, **Always allow** or **Deny**.

To change what Ren can do without asking, see [Permissions](/docs/permissions/).

## The side panel

The right side panel shows what Ren does on the computer of the chat. Open it with the panel button at the top right of the chat. Select **+** to add a tab.

<Screenshot
  shot="chats/tab-menu"
  alt="The + menu of the side panel with Browser, Files, Changes, Activity and Terminal"
  caption="Select + to open a tab."
/>

| Tab      | What it shows                             |
| -------- | ----------------------------------------- |
| Activity | Every step Ren took in this chat          |
| Changes  | The files Ren created or edited, as diffs |
| Files    | The files on the computer of the chat     |
| Browser  | The pages Ren opens                       |
| Terminal | A shell on the computer of the chat       |

### Activity

Activity lists every step Ren took, such as each command it ran and each file it edited. Open a step to see its inputs and outputs. Select **Worked for** above a reply to jump to that reply's steps.

### Changes

Changes shows each changed file, with removed lines in red and added lines in green:

- **Repository**: every change in the repository since its last commit, by Ren or by you.
- **Ren's edits**: only the files Ren edited in this chat.

Select a file in the tree to jump to it. The buttons above the diff switch between one column and side by side.

### Files

Files shows the file tree of the computer of the chat. Select a file to open it in the viewer. A file path in a reply also opens the file here.

| File type                                                    | What the viewer does                               |
| ------------------------------------------------------------ | -------------------------------------------------- |
| Images, PDFs, spreadsheets, Word documents, PowerPoint decks | Shows a preview                                    |
| Text and code                                                | Shows the file with line numbers                   |
| HTML pages                                                   | Shows the page, with zoom and **Open full screen** |
| Audio and video                                              | Plays the file                                     |
| Other formats                                                | Shows the type and size, with **Download**         |

You can also send `/open <file>`.

### Browser

Browser shows the page that Ren uses, live. Select **Take control** to use the page yourself, for example to sign in. Select **Give control back** when you are done.

### Terminal

Terminal opens a shell on the computer of the chat. You can open more than one. You can also send `/terminal`.

## Run a command

To run one command on the computer of the chat without opening a terminal, type `!` in an empty composer, or press `⇧⌘X`. The composer switches to shell mode: it shows `$` and **Shell**.

<Screenshot
  shot="chats/shell-mode"
  frame="detail"
  alt="The composer in shell mode with $ git status --short, the Shell label and the run button"
  caption="Type ! to run a command."
/>

Type the command and press Enter. It runs in the background on the computer of the chat, and its output shows in the chat when it finishes. Ren doesn't answer it, but it sees the command and its output with your next message, so you can ask about them.

To go back to messages, press Esc, or press Backspace in the empty composer.

## Quote or comment on a reply

Select text in a reply of Ren to quote it in your next message, or to comment on it.

## Edit your messages

- **Edit:** hover over a message you sent, select `✎`, change the text and select **Send**. This replaces the message and removes everything after it.

<Screenshot
  shot="chats/edit-hover"
  alt="A sent message on hover, with the time, a pencil button and a copy button below it"
  caption="Hover over your message to edit it."
/>

- **Retry:** if a message shows **Not sent**, select **Retry**.
- **Undo:** send `/undo` to undo your last message, and `/redo` to bring it back.
- **Find:** press `⌘F` to search the chat.

## Chat actions

Select `⋯` at the top right of the chat to rename the chat, copy its link or archive it.

When the chat is linked to tasks, pull requests, issues or channel threads, the same menu lists them. An archived chat leaves your chat list.

## Commands

Type `/` in the composer to see the commands. Keep typing to filter them, then press Enter.

## Good to know

- On Windows and Linux, use Ctrl instead of `⌘`.
- A chat from a channel or a schedule denies any action that needs approval, unless you allow it in the [permissions](/docs/permissions/).
- If credits run out during a reply, Ren stops. After an admin adds credits, select **Continue**.
