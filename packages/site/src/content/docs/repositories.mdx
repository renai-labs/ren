The **Repositories** page of a [space](/docs/spaces/) lists the git repositories its chats read. Each chat gets a read-only copy of each repository. To change code, Ren clones the repository in the chat.

## Add a repository

<Steps>

1. Open **Space → Repositories**, and select **Add repositories**.
2. Search your GitHub repositories, or paste an address such as `https://github.com/renai-labs/ren`.
3. In the repository's `⋯`, select **Edit**, and write a description of what it holds, such as "The Ren monorepo: the app, the server and the docs site." Ren uses only the description to pick a repository.
4. Optionally change the alias, the short name Ren uses for it, and the branch. Without a branch, Ren uses the repository's default branch.

</Steps>

To add a private repository, [connect GitHub](/docs/channels/github/#connect-github) for your organization and give the Ren app access to the repository. Ren checks that access when you add it.

## Choose a repository for a chat

Ren picks the repository from your request and the descriptions. To pick it yourself, select the repositories button in the composer, or type `@` and pick it under **Repositories**.

To say which repository every chat should use, write it in the space's [instructions](/docs/instructions/).

## Change or remove a repository

In the repository's `⋯`, select **Edit** to change its description, alias or branch, or **Remove**. Chats in the space stop reading a removed repository.

To see what Ren changed in a clone during a chat, open the chat's [Changes](/docs/chats/#changes) tab.

## GitHub access in chats

| Space          | Ren uses             | Commits and pull requests show as |
| -------------- | -------------------- | --------------------------------- |
| Personal space | Your GitHub sign-in  | You                               |
| Shared space   | The Ren app's access | `renagent[bot]`                   |

Without your GitHub sign-in, your personal space also uses the Ren app's access.

## Good to know

- Each chat works in its own folder on the space's machine, so chats do not change each other's files.
