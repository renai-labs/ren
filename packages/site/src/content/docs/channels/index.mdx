A channel links a [space](/docs/spaces/) to a place where your team already communicates, such as a Slack channel or a GitHub repository.

| Channel                          | A space links to    | One chat is                |
| -------------------------------- | ------------------- | -------------------------- |
| [Slack](/docs/channels/slack/)   | A Slack channel     | A Slack thread             |
| [GitHub](/docs/channels/github/) | A GitHub repository | An issue or a pull request |

## How a channel works

When someone mentions Ren in a linked place, Ren starts a chat in the linked space, with that space's apps, repositories and instructions. It replies in the same Slack thread, issue or pull request. A reply there that mentions Ren continues the chat.

Each chat also shows in the app, so you can continue it there. Its header links back to the conversation.

## Link a place to a space

First connect Slack or GitHub in **Settings → Channels**. Any member can connect them. Then link places in one of two ways. The two ways start with a different fallback user (see [Who Ren runs as](#who-ren-runs-as)).

### From a space

Use this to link places to a space you are a member of.

<Steps>

1. Open **Space → Channels**, and select **Add channel**.

2. Pick the Slack channels or repositories, and select **Link**.

</Steps>

### From settings

Use this to see every place and its space in one list. An admin can link places to any shared space.

<Steps>

1. Open **Settings → Channels → Slack** or **GitHub**, and select **Add channel** or **Add repo**.

2. Pick the places and the space, and select **Link**.

</Steps>

Each place links to one space.

## Who Ren runs as

Ren runs each message as the first of these that can work in the space. It uses that person's access.

| Order | Ren runs as       | How Ren finds them                                                                                          |
| ----- | ----------------- | ----------------------------------------------------------------------------------------------------------- |
| 1     | The sender        | By the Slack or GitHub account they signed in to Ren with, or by the email on their Slack or GitHub profile |
| 2     | The fallback user | The person in **Run unknown senders as**. Select `✎` on a linked place to change it.                        |
| 3     | Nobody            | Ren does not run the message, and replies with the reason                                                   |

The fallback user of a new link depends on where you link it:

| Linked from             | Slack channel or private repository | Public repository |
| ----------------------- | ----------------------------------- | ----------------- |
| **Space → Channels**    | You                                 | **Nobody**        |
| **Settings → Channels** | **Nobody**                          | **Nobody**        |

A fallback user lets anyone in the place work with that person's access. Select `✎` to check it after you link.

Each channel's page lists the fallback user of places that are not linked.

| Ren replies                                                      | Why                                                        | Fix                                                                |
| ---------------------------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------ |
| **Link your account to Ren so I can respond here.**              | Ren cannot match the sender, and there is no fallback user | Sign in to Ren with Slack or GitHub, or use the same email on both |
| **You need access to this channel's space in Ren.**              | The sender is a member, but not of the space               | Ask a space member to invite you                                   |
| **I can't respond here until this channel's access is updated.** | The fallback user cannot work in the space anymore         | Pick another person in **Run unknown senders as**                  |

## Unlink or disconnect

- To stop Ren answering in one place, open `⋯` on its row and select **Unlink**.
- To disconnect Slack or GitHub, open it in **Settings → Channels** and select **Disconnect**. This unlinks every place. Only an admin or the person who connected it can disconnect.

## Good to know

- A chat from a channel cannot ask you to approve an action. Allow what it needs in [permissions](/docs/permissions/).
- To give Ren tools in a service, such as reading code on GitHub, add an [app](/docs/apps/). A channel only lets people ask Ren for work.
