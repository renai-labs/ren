## Connect Slack

<Steps>

1. Open **Settings → Channels → Slack**.

2. Select **Connect Slack** and approve Ren in your Slack workspace.

</Steps>

Then [link each Slack channel to a space](/docs/channels/#link-a-place-to-a-space). If a channel is missing from the list, run `/invite @Ren` in it.

Any member can connect Slack. That person becomes the fallback user of Slack channels that are not linked.

## Talk to Ren

| Where            | Start a chat   | Continue it                                                 |
| ---------------- | -------------- | ----------------------------------------------------------- |
| A Slack channel  | Mention `@Ren` | Reply in the Slack thread and mention `@Ren` again          |
| A direct message | Send a message | Reply in its Slack thread. A new message starts a new chat. |

Ren reacts 👀 when it starts, then ✅ when it is done or ❌ when it fails. If only 👀 shows, open the chat in the app.

When you mention Ren in a Slack thread, it reads the messages since its last mention, up to 12,000 characters and 10 files.

## Where Ren works

| Message from                              | Space                                                           |
| ----------------------------------------- | --------------------------------------------------------------- |
| A thread linked to a [task](/docs/tasks/) | The space of the task                                           |
| A linked Slack channel                    | The linked space                                                |
| Any other Slack channel                   | The oldest space of the organization, such as **General Space** |
| A direct message                          | Your personal space                                             |

## Who Ren runs as

Ren matches the sender by the Slack account they signed in to Ren with, or by the email on their Slack profile. When it cannot, it uses the [fallback user](/docs/channels/#who-ren-runs-as):

| Message from              | Fallback user                                |
| ------------------------- | -------------------------------------------- |
| A linked Slack channel    | The person in **Run unknown senders as**     |
| Any other Slack channel   | The person who connected Slack               |
| A thread linked to a task | None: only Ren members                       |
| A direct message          | None: only Ren members with a personal space |

## Slack tools

Connecting Slack also gives Ren Slack tools, such as sending a message or searching a channel, in each space from [Where Ren works](#where-ren-works). Ren posts as its own Slack bot.

## Task cards

When you paste the link of a [task](/docs/tasks/) in Slack, Ren shows a card with its title and status. In a thread linked to a task, the card stays up to date. Its buttons act as the person who selects them.

## Good to know

- Ren reads the files in your message, up to 32 MB each. It skips a larger file and gets a note about it.
- Ren ignores direct messages from other bots. A mention from another app in a channel runs as the fallback user.
- Ren can't show a connect card in Slack. To connect an app, open the chat in the app.
