The Ren docs are available as Markdown files, so an AI agent can read them before it helps you with Ren.

## Files

| URL                                | What it contains                                                       | When to use it                                                   |
| ---------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `https://useren.ai/llms.txt`       | Each page's title, link and one-sentence description, by sidebar group | The agent can fetch URLs and should read only the pages it needs |
| `https://useren.ai/llms-full.txt`  | Every page as Markdown, in sidebar order                               | The agent should read all the docs at once                       |
| `https://useren.ai/llms-small.txt` | Every page as Markdown, without code blocks                            | The agent has less room for context                              |

Without code blocks, `llms-small.txt` loses the commands and configuration examples of the Developers pages. For CLI, API or infrastructure-as-code work, use `llms-full.txt` or the pages themselves.

## One page

Add `/raw` before a page's path and `.md` after it to get that page as Markdown:

| Page                                     | Markdown                                       |
| ---------------------------------------- | ---------------------------------------------- |
| `https://useren.ai/docs/`                | `https://useren.ai/raw/docs.md`                |
| `https://useren.ai/docs/tasks/`          | `https://useren.ai/raw/docs/tasks.md`          |
| `https://useren.ai/docs/developers/cli/` | `https://useren.ai/raw/docs/developers/cli.md` |

On each page, under **On this page**, **Copy page** copies its Markdown, **View as Markdown** opens it, and **Ask Ren about this page** opens Ren with a prompt to read it.

## Example

Paste this into your agent:

```text
Read https://useren.ai/llms.txt and open the Ren docs pages you need as
Markdown, at https://useren.ai/raw/docs/<path>.md. Then help me add a
reviewer agent to the engineering space of my Acme organization. Use the
Ren CLI, and show me each command before you run it.
```
