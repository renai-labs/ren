The Ren docs are available as Markdown files for AI agents. Give one of these files to your agent, and it can help you work with Ren.

```text
https://useren.ai/llms-full.txt
```

## Files

| File                                 | When to use it                                                 |
| ------------------------------------ | -------------------------------------------------------------- |
| [`/llms.txt`](/llms.txt)             | Let the agent choose pages from an index of titles and links.  |
| [`/llms-full.txt`](/llms-full.txt)   | Give the agent all the docs at once.                           |
| [`/llms-small.txt`](/llms-small.txt) | Use shorter docs when the agent has limited space for context. |

## Use the docs with your agent

Give your agent the URL above, or paste the file contents into your agent.

## Use one page

1. Open the page.
2. Select **Copy page**.

The **Copy page** menu also shows **Open Markdown**, **Chat in Claude**, and **Chat in ChatGPT**.

## Good to know

- The files contain only published pages.
- Each page is available as Markdown at `/raw/<page-path>.md`.
- This page is at [`/raw/docs/developers/llms-txt.md`](/raw/docs/developers/llms-txt.md).
