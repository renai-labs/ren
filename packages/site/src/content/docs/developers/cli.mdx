The Ren CLI, `ren`, manages spaces, tasks, agents, and settings from a terminal or a script. Coding agents with shell access can run it too. The CLI supports more operations than the [MCP server](/docs/developers/mcp/).

```sh
curl -fsSL https://useren.ai/install | bash
```

## When to use the CLI

| Surface                      | Use it to                                                           |
| ---------------------------- | ------------------------------------------------------------------- |
| CLI                          | Manage Ren from a terminal, a script, or a coding agent             |
| [Web app](/docs/#web-app)    | Chat with Ren and review its work                                   |
| [MCP](/docs/developers/mcp/) | Connect AI tools that cannot run shell commands, like chat websites |

## Install

The installer works on macOS and Linux, on arm64 and x64. It installs `ren` to `~/.ren/bin`, adds that folder to your `PATH`, and runs `ren login` after the installation.

```sh
curl -fsSL https://useren.ai/install | bash
```

To skip the sign-in:

```sh
curl -fsSL https://useren.ai/install | bash -s -- --no-init
```

To install version `0.1.0`:

```sh
curl -fsSL https://useren.ai/install | bash -s -- --version 0.1.0
```

## Sign in

<Steps>

1. Run `ren login`. It opens Ren in your browser.
2. Choose your organization and allow access. To print the sign-in URL instead of opening the browser, use `ren login --no-browser`.
3. Run `ren whoami` to confirm. It shows your user and your organization.

</Steps>

To switch to another organization, run `ren login` again and choose it.

## Check it worked

Ask your coding agent:

```text
Summarize my Ren setup using the ren CLI.
```

The answer must name your organization and list its spaces.

## Commands

Commands follow the pattern `ren <noun> <verb>`. A slug works wherever an ID does.

```sh
ren space list
ren space create --name Docs --slug docs
ren task create --space docs --title "Fix the build"
ren schedule run nightly
```

In a terminal, the CLI prints tables. When you pipe it or pass `--output json`, it prints JSON, so scripts and agents can read it.

## Good to know

- The CLI cannot send chat messages yet. Send them from the web app or a channel.
- Ren stores your sign-in in `~/.config/ren/credentials.json`. To sign out, run `ren logout`.
- In CI, set `REN_TOKEN` instead of running `ren login`.
- For every command and flag, run `ren --help` or `ren <command> --help`.
- To update the CLI, run `ren upgrade`.
