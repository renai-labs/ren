The `ren` command manages your Ren organization from a terminal or a script.

## Install

The installer runs on macOS and on Linux distributions that use glibc, such as Ubuntu and Debian.

```sh
curl -fsSL https://useren.ai/install | bash
```

It puts `ren` in `~/.ren/bin`, adds that folder to your `PATH` and then signs you in. If your terminal can't find `ren` afterwards, open a new one.

To pass options, add them after `bash -s --`:

```sh
curl -fsSL https://useren.ai/install | bash -s -- --version 0.2.0
```

| Option               | What it does                                   |
| -------------------- | ---------------------------------------------- |
| `--version <number>` | Installs that release instead of the latest    |
| `--no-modify-path`   | Leaves your `PATH` and shell profile unchanged |
| `--no-init`          | Skips sign-in                                  |

## Sign in

The installer does this for you the first time. Run it yourself to sign in later or to switch to another organization:

```sh
ren login
```

Your browser opens. Sign in to Ren, pick the **Organization** and click **Allow**. From then on, every command runs as you in that organization, so it can do what you can do in the app and nothing more.

If the browser doesn't open, run `ren login --no-browser` and open the link it prints on the same computer.

To check who you're signed in as:

```sh
ren whoami
```

```text title="Output"
ada@acme.com in Acme
```

If a command says `Space not found.` for a space you can open in the app, you're probably signed in to a different organization.

## Run commands

Commands take the form `ren <resource> <action>`. Where a command asks for a space or an agent, pass its slug or its ID.

```sh
ren space list
ren space get engineering
ren space agent list engineering
ren task list --space engineering
```

Add `--help` at any level to see the actions and their options.

```sh
ren --help
ren task create --help
```

[CLI commands](/docs/developers/cli-commands/) lists every command. To keep your setup as files in Git, use `ren infra`; see [Infrastructure as code](/docs/developers/iac/).

## Use in scripts

In a terminal, `ren` prints readable text. When you pipe or redirect it, it prints JSON instead, so a script can read the result. Pass `--output json` or `--output pretty` to choose for yourself.

```sh
ren space list | jq -r '.items[].slug'
```

Results go to stdout. Progress and errors go to stderr, so `ren space list > spaces.json` saves only the result.

## Update

```sh
ren upgrade
```

Add a version, such as `ren upgrade 0.2.0`, to install that release. Once a day, `ren` tells you in the terminal when a newer release is out.

## Sign out and uninstall

`ren logout` signs you out and revokes the CLI's access. To remove the CLI, sign out, then delete its folders:

```sh
ren logout
rm -rf ~/.ren/bin ~/.config/ren
```

Then remove the `~/.ren/bin` line from your shell profile, such as `~/.zshrc`. If the installer linked `ren` into `~/.local/bin` or `~/bin`, delete that link too.
