The **Compute** page of a [space](/docs/spaces/) sets the [machines](/docs/machines/) its chats run on.

## Brain

| Setting         | Choices                                                                                                    |
| --------------- | ---------------------------------------------------------------------------------------------------------- |
| **Brain scope** | **Per space**: all chats share one brain. **Per chat**: each chat gets its own. Applies to new chats only. |
| **Provider**    | Where the brain runs                                                                                       |
| **Machine**     | **Ren's standard machine**, or a machine your organization made                                            |

## Hand

| Choice                          | Use it when                                                     |
| ------------------------------- | --------------------------------------------------------------- |
| **The brain's machine**         | The default. Tools run next to the agent.                       |
| A machine, **separate machine** | The tools need their own packages, size or network limits       |
| **No tools**                    | The space only talks, searches and uses apps: no files or shell |

## Apply a change

A change shows **Change pending** until each brain or hand starts again. That happens on the next message after the space is idle for about 10 minutes.

To apply it now, select **Shut down space**. All work in the space stops, the files on its machines are deleted, and each brain and hand starts again with the new settings at the next message. Save what must last in [Drive](/docs/drive/), or push code to its repository, first.

**Last shutdown** shows when the space last shut down, and any problem it had.

To keep these settings in Git, see [Spaces](/docs/developers/iac/spaces/#runtime) on the Developers tab.
