An organization is your company in Ren. It holds your [members](/docs/members/) and [spaces](/docs/spaces/), and the settings that every space shares. Admins change them in **Settings**.

## What applies to every space

| Setting                                        | Where                                 |
| ---------------------------------------------- | ------------------------------------- |
| Name, logo and **Default model**               | **Settings → General**                |
| [Instructions](/docs/instructions/)            | **Settings → General → Instructions** |
| [Members](/docs/members/) and roles            | **Settings → Members**                |
| [Permissions](/docs/permissions/)              | **Settings → Permissions**            |
| [Memory](/docs/memory/)                        | **Settings → Memory**                 |
| [Models](/docs/model-providers/)               | **Settings → Providers**              |
| [Secrets and app accounts](/docs/credentials/) | **Settings → Credentials**            |
| [Slack and GitHub](/docs/channels/)            | **Settings → Channels**               |
| [Machines](/docs/machines/)                    | **Settings → Machines**               |
| [Usage](/docs/usage/)                          | **Settings → Usage**                  |
| [Plan and invoices](/docs/billing/)            | **Settings → Billing & plans**        |

A space can set its own default model, instructions and permissions on top of the organization's.

## Default model

New chats start with the organization's **Default model**, unless the space sets its own. You can still pick another model in each chat.

## Switch or create an organization

You can belong to more than one organization, such as your company's and a client's. Select your name at the bottom of the sidebar, then the organization to switch to. Each organization has its own spaces, chats and settings.

To make a new one, select **Create organization** in the same menu.
