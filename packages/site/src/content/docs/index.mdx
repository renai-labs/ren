## How Ren is organized

Ren organizes work in four levels. Each level sits inside the one above it. Use the levels to keep each team or client apart, and to give each kind of work its own setup.

<FactoryDiagram />

### The four levels

| Level                               | What it is                                           | What it holds or decides                                    |
| ----------------------------------- | ---------------------------------------------------- | ----------------------------------------------------------- |
| [Organization](/docs/organisation/) | Your company or account                              | Members, billing, and settings that apply everywhere        |
| [Space](/docs/spaces/)              | A team or client inside the organization             | Who can see the work. A space runs on its own machine.      |
| [Project](/docs/concepts/projects/) | One kind of work inside a space, such as code review | The instructions, tools, and storage Ren uses for that work |
| [Chat](/docs/chats/)                | One request to Ren inside a project                  | Everything Ren did to answer the request                    |

### Spaces

Each organization starts with a **General** space for all members. Each member gets a private **Personal** space. Add spaces for teams or clients.

### Example: a company's internal agents

Northwind's engineers share the **Engineering** space in their company's organization. Engineering has two projects:

- **Code review**, with the team's repositories and review instructions.
- **Incident triage**, with access to the on-call tools and a runbook skill.

Code review uses separate chats for the login fix and the new API. Both chats share the repositories and review instructions of the project. Incident triage uses a separate project because it needs different tools and instructions.

### Example: an agency serving clients

Brightline is a marketing agency. Its organization is **Brightline**, with one space per client, like **Acme**. The Acme space has two projects:

- **Campaign reporting**, connected to Acme's ad accounts.
- **Content production**, with Acme's brand guidelines and assets.

Campaign reporting uses separate chats for weekly reports and campaign comparisons. Only Acme's team joins the Acme space. Acme's tool accounts use space credentials. The space of another client cannot get access to Acme's work or credentials.

### What else you configure

Most features attach to a project or a space.

| Level               | Features                                                                                                                                                                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Project             | [Apps](/docs/apps/), [skills](/docs/apps/#skills), [custom MCPs](/docs/apps/#custom-mcps), [repositories](/docs/concepts/projects/), [channels](/docs/channels/), [schedules](/docs/automations/), and [file and memory stores](/docs/drive/) |
| Space               | [Databases](/docs/drive/), [artifacts](/docs/artifacts/), [environments](/docs/machines/), and [tasks](/docs/tasks/)                                                                                                                          |
| More than one level | [Credentials](/docs/credentials/) and [instructions](/docs/concepts/projects/)                                                                                                                                                                |

### Good to know

- Tasks attach to a space. You can assign a task to a project.
- Credentials belong to the organization, a space, or your personal account.
- You can set instructions on the organization, a space, and a project.
- [Blueprints](/docs/concepts/blueprints/) add a ready-made project or space to your organization.

## Web app

The [web app](https://useren.ai/login) lets you chat with Ren, attach files, and review its work in your browser. Use it to follow each step of the work, answer questions from Ren, and manage Ren.

### When to use the web app

| Use                                      | What you do                                                                                                                |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **Inspect work**                         | Expand individual steps to see the actions of Ren. Send more instructions between messages.                                |
| **Review results**                       | Open the reports, dashboards, and files that Ren creates, next to the chat that made them.                                 |
| **Answer questions and approve actions** | Respond in the chat.                                                                                                       |
| **Manage Ren**                           | Create [spaces](/docs/spaces/) and [projects](/docs/concepts/projects/), invite teammates, connect apps, and map channels. |

### Other surfaces

| Surface                      | Use it to                                                                   |
| ---------------------------- | --------------------------------------------------------------------------- |
| [Channels](/docs/channels/)  | Send requests from team conversations. Continue those chats in the web app. |
| [CLI](/docs/developers/cli/) | Manage Ren from a terminal                                                  |
| [MCP](/docs/developers/mcp/) | Manage Ren from another AI tool                                             |

### Assign work

Ren can research topics, summarize data from apps, analyze files, write code, and create reports, dashboards, and pages. For example, ask Ren to turn meeting notes into a follow-up email.

| Hand off work as                 | Use it to                                    |
| -------------------------------- | -------------------------------------------- |
| A [chat](/docs/chats/)           | Delegate a one-off request                   |
| A [task](/docs/tasks/)           | Track work that people and Ren share         |
| A [schedule](/docs/automations/) | Repeat work on a timer, like a weekly report |

### Good to know

- [Channel](/docs/channels/) chats and [scheduled](/docs/automations/) chats cannot ask questions. They deny actions that need approval.
- [Apps](/docs/apps/) give Ren tools.
- Files and repositories give Ren context for the work.
- You can continue a channel chat in the web app.
