An artifact is an app that Ren builds in a [space](/docs/spaces/) and publishes at its own link, such as a dashboard or report.

## Artifact visibility

Every member of a space can see its artifacts. Open **Drive → Artifacts** from the main sidebar to see the artifacts of all your spaces, or from a space's sidebar to see the artifacts of that space only.

Anyone with the link can open an artifact without signing in. You cannot limit who opens it. Share the link only with people who must see the artifact.

## Build an artifact

<Steps>

1. Select **Build with Ren** and choose the space.

2. Finish the prompt, such as `Build an artifact: a dashboard of this month's orders by region`, and send it.

3. When Ren replies with the link, open it.

</Steps>

Ren also builds an artifact when you ask for a site or a page in any chat.

To change an artifact, select **Edit with Ren** in `⋯`. A chat opens with the artifact mentioned.

## Keep an artifact up to date

An artifact can read current data each time someone opens it. To refresh its data at set times, create an [automation](/docs/automations/), such as `Every weekday at 8am, refresh the orders dashboard with yesterday's orders.`

## Apps that keep data

An artifact can run its own server code and save data in its own database, such as a form that stores answers or a tracker that people update. The data stays when Ren publishes a new version.

## Links

The link of an artifact is `https://<name>.useren.site`. Ren makes the name from the title, such as `orders-dashboard`.

To change the title or the link, select **Rename…** in `⋯`. A name has 1 to 63 lowercase letters, digits and hyphens, and is unique across Ren. The old link stops at once, and another artifact can take the old name.

## Status

| Status         | Meaning                                                       |
| -------------- | ------------------------------------------------------------- |
| **Updating**   | Ren is publishing a new version. The link shows the last one. |
| **Not served** | The artifact has no link. Ask Ren to publish it in a chat.    |

A stopped artifact opens a page that says it is gone.

## Archive an artifact

Select **Archive** in `⋯` and confirm. The link stops for everyone, the name becomes free, and the artifact leaves **Artifacts**. Ren keeps its files and data. You cannot restore it in the app.

## Good to know

- Each artifact also has a fixed link, `https://art-<id>.useren.site`. Renaming does not change it. Only archiving stops it.
- An artifact has up to 2,000 files, 25 MiB each and 200 MiB in total.
- There is no download. Ask Ren for the files you need, such as a PDF or a CSV of the data. Ren saves them to [Drive](/docs/drive/).
- Links from Ren v1 open the same artifact.
