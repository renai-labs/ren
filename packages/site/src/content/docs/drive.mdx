Drive holds the files that people and Ren share, such as brand guidelines, price lists and the reports Ren writes. The organization has one drive, and each [space](/docs/spaces/) has its own from the start.

## Drive visibility

Everyone in the organization can open the organization's drive, and only a space's members can open its drive. **Drive** in the main sidebar and in a space's sidebar opens the organization's drive, with a folder for each of your spaces, and that space's drive.

| Who                         | Organization drive | Space drive    |
| --------------------------- | ------------------ | -------------- |
| You                         | Read and write     | Read and write |
| Ren, in a chat of the space | Read only          | Read and write |

## Upload files

Select **Upload**, or drop files on the page. Ren puts them in the folder you have open.

## Open, download or delete a file

Select a file to open it in the viewer. The viewer shows the same file types as the Files tab of a [chat](/docs/chats/).

To download or delete a file, select **Download** or **Delete** in `⋯`. A deleted file leaves the drive for everyone, and you cannot undo it.

## Use drive files in a chat

Ren reads the drives of the space and the organization in every chat. To point Ren at one file, type `@`, pick **Files**, then the file. To keep a file that Ren made, ask Ren to save it to the drive.

## Good to know

- Each file can be up to 100 MB.
- Files outside Drive can be lost when Ren replaces the machine. Save what must last in Drive.
- For code, use a [repository](/docs/repositories/). For data that an app reads and writes, use an [artifact that keeps data](/docs/artifacts/#apps-that-keep-data).
- Files you attach in a chat stay with the chat and do not show in Drive.
