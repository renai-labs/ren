A channel lets your team ask Ren for work where they already talk: in Slack, or on GitHub issues and pull requests. Ren works in a [space](/docs/spaces/), and replies in the same thread.

| Channel | How you reach Ren                                                              | One chat is                |
| ------- | ------------------------------------------------------------------------------ | -------------------------- |
| Slack   | Mention `@Ren` in a channel, or send Ren a direct message                      | A Slack thread             |
| GitHub  | Mention the Ren app in an issue, a pull request, a comment or a review comment | An issue or a pull request |

Each chat also shows in the app, so you can continue it there. Its header links back to the thread.

## Connect Slack or GitHub

1. Open **Settings → Channels** and select Slack or GitHub.
2. Select **Connect Slack** or **Connect GitHub**, and approve Ren in the Slack workspace or on the GitHub organization. On GitHub, choose the repositories Ren can see.

To add a repository later, give the Ren app access to it on GitHub.

## Link a channel or repository to a space

Link a Slack channel or a repository to the space whose apps, repositories and instructions the work needs.

1. Open the space, then **Channels**, and select **Add channel**.
2. Pick the Slack channels or repositories, then link them.

You can also link them from Slack or GitHub in **Settings → Channels**. Each Slack channel or repository works in one space. Members of a space can link places to it.

## Where Ren works

| Message from                              | Space                                                           |
| ----------------------------------------- | --------------------------------------------------------------- |
| A thread linked to a [task](/docs/tasks/) | The space of the task                                           |
| A linked Slack channel or repository      | The linked space                                                |
| Any other Slack channel or repository     | The oldest space of the organization, such as **General Space** |
| A Slack direct message                    | The sender's personal space                                     |

## Who Ren runs as

Ren runs each message as the person who sent it, so it uses their access. It matches the sender to a Ren member by the account they signed in to Ren with, or by the email on their Slack or GitHub profile.

When the sender has no Ren account, or is not a member of the space, Ren runs as the person in **Run unknown senders as**. Select `✎` on a linked place to change it, or pick **Nobody** to answer only Ren members.

In a place that is not linked, Ren runs unknown senders as the person who connected Slack or GitHub, except in a public repository, where it answers only Ren members.

## Triggers

A trigger starts Ren without a mention. On a linked repository, turn on **Review pull requests when ready** to have Ren review each pull request when it is opened or marked ready for review.

## Unlink or disconnect

- To stop Ren answering in one place, open `⋯` on its row and select **Unlink**.
- To disconnect Slack or GitHub, open it in **Settings → Channels** and select **Disconnect**. This unlinks every place, and Ren stops answering there.

## Good to know

- A chat from a channel cannot ask you to approve an action. Allow what it needs in [permissions](/docs/permissions/).
- In each Slack thread and GitHub issue or pull request linked to a task, Ren posts a card with the task's title and status, and keeps it up to date.
