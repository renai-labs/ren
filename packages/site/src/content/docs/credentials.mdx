Credentials are the sign-ins and keys that Ren uses to work in other services: the [app accounts](/docs/apps/#apps-and-accounts) that you connect, and the secrets that you paste, such as a Stripe API key.

Open **Settings → Credentials**:

| Tab         | Shows                                                                    |
| ----------- | ------------------------------------------------------------------------ |
| **Apps**    | The apps that your spaces use, their accounts and where each one is used |
| **Secrets** | The secrets that you can use, the websites they go to, and their owner   |

Each space also has a **Secrets** page with the secrets of that space only.

## How Ren uses a secret

Ren never gives the real value to the chat. A chat sees an env var, such as `STRIPE_API_KEY`, that holds `ren:STRIPE_API_KEY`. When a tool or a command sends a request to one of the secret's websites with that text in a header, Ren puts the real value in on the way out.

This keeps the value out of the chat, the files and the command output. It also means a secret works only on the websites you list for it.

## Add a secret

<Steps>

1. Open **Settings → Credentials → Secrets**, and select **Add secret**.
2. Type the env name in `UPPER_SNAKE_CASE`, such as `STRIPE_API_KEY`. You cannot change it later.
3. Paste the secret.
4. Under **Who can use it**, pick the organization, a space, or **Only me**.
5. Type the websites that get the secret, such as `api.stripe.com`, or turn on **Use on any website**.
6. Select **Save secret**.

</Steps>

To add a secret to one space, open **Space → Secrets**, and select **Add secret**. To reuse a secret of another space, select **Copy from a space** in the same menu.

## Who can use a secret

| Owner        | Chats that can use it          | Who can see and change it               |
| ------------ | ------------------------------ | --------------------------------------- |
| Organization | Every chat in the organization | Every member. Any member can delete it. |
| A space      | Every chat in that space       | The members of that space               |
| **Only me**  | Chats in your personal space   | You. An admin can see and delete it.    |

When two secrets have the same env name, Ren uses yours first, then the space's, then the organization's.

When an app needs a key, connect it as an [app account](/docs/apps/#apps-and-accounts). Make a secret only for your own commands and scripts.

## Change a secret

Select a secret to change its display name, who can use it or its websites. Open `⋯` on the secret for the rest:

- **Rotate**: paste a new secret. Chats use it from their next request.
- **Move** or **Copy**: give it another owner. A copy is a separate secret. You can't copy an app sign-in.
- **Delete**: chats lose it at once.

When an app account shows **Sign-in expired**, open it from **Apps** and select **Reconnect**.

## Good to know

- Give Ren a key with only the access the work needs, such as a restricted Stripe key instead of the full secret key.
- To give Ren a key for a service that has an app, connect an [app account](/docs/apps/) instead. The app gives Ren tools as well as the key.
- Each owner can have up to 100 secrets.
