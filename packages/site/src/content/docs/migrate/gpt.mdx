Copy your Codex skills and memory to Ren. Then use them to run work in the cloud, on a schedule, or with your team.

### Install the Ren plugin

The plugin adds the Ren MCP server and skills to configure and manage Ren.

<Steps>

1. Add the Ren marketplace:

   ```sh
   codex plugin marketplace add renai-labs/registry
   ```

2. Open the Codex plugin directory.
3. Find **Ren** in the `renai-labs` marketplace.
4. Install the plugin.
5. When Codex first connects to Ren, sign in and approve access in the browser. See [MCP](/docs/surfaces/mcp/).

</Steps>

### Run onboarding

Onboarding is a skill in the plugin, not a slash command. Ask for it:

```text
Use the ren-onboarding skill to set me up on Ren.
```

Codex uses your existing context and offers a tour, a demo, or help to configure recurring work. For recurring work, it asks what to delegate. Then it creates a project in your personal space and gives you the web app link. It also asks if it must connect required accounts, like Gmail.

### Push your skills

Ask Codex to copy your local skills into Ren:

```text
Use the ren-systems-architect skill to push my local Codex skills to Ren as personal skills.
Skip skills that already exist in Ren. List the skills you created.
```

Codex creates one Ren [skill](/docs/concepts/skills/) from each skill folder, with its `SKILL.md` and supporting files. Ren checks each uploaded `SKILL.md` against the skill requirements. Codex lists the skills that Ren rejects.

### Push your memory

Ask Codex to copy your standing instructions and notes:

```text
Use the ren-systems-architect skill to push my AGENTS.md files and anything you remember about me to my personal memory store in Ren.
```

Codex uploads your instructions and notes to your personal memory store, such as `Alex Rivera Memory`. The **Default** project of your personal space uses this store. See [Storage](/docs/concepts/storage/).

### Make sure it worked

| What   | Where to look                                                                                                                       |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Skills | In the web app, open **Marketplace → Skills** and switch to **Installed**. Your pushed skills show as personal.                     |
| Memory | Open the **Default** project of your personal space. Select **Storage → Memory**. Open your memory store to see the uploaded files. |

## ChatGPT

Save the ChatGPT summary of your work and preferences to the Ren memory.

### Connect Ren to ChatGPT

Add Ren as a custom connector in ChatGPT. See [MCP](/docs/surfaces/mcp/).

### Push your memory from ChatGPT

Start a new ChatGPT chat with the Ren connector turned on, and send:

```text
Record everything you know about me and my work. Include my role, team, projects, tools, and work preferences. Use the
Ren connector to save chatgpt-memory.md in my personal memory store.
```

ChatGPT saves the file in your personal memory store, such as `Alex Rivera Memory`. The **Default** project of your personal space uses this store.

To review the file, open the **Default** project of your personal space and select **Storage → Memory**. See [Storage](/docs/concepts/storage/).

### Move a ChatGPT project

Create a [Ren project](/docs/concepts/projects/). Copy the instructions of the ChatGPT project into the **Instructions** field of the Ren project.

## Good to know

- Personal skills are visible only to you. To share a skill with your organization, ask Codex to create it at the organization level.
- Codex needs network access to reach Ren. Without it, onboarding stops and sends you to the [web app](https://useren.ai/app).
- The ChatGPT file holds the summary that ChatGPT selects, not a complete memory export. Review it before you use it.
- Automatic project migration is not available.
