An app connects Ren to a service like Gmail, Linear, HubSpot, or Shopify. For example, Gmail lets Ren read, summarize, and draft email. In the API and CLI, an app is a blueprint with `kind: app`.

```text
@Gmail summarize my unread email from today.
```

## How apps work

An app usually gives Ren tools through an MCP server. It can also include [skills](/docs/concepts/skills/) that explain how to use those tools. You connect the account or key that the app needs.

Add an app to a [project](/docs/concepts/projects/) to make it available in every chat of that project. Projects in the same space reuse the connected account.

| Part                                | What it does                           | Linear example                  |
| ----------------------------------- | -------------------------------------- | ------------------------------- |
| App                                 | Gives Ren tools                        | Reads and updates issues        |
| [Channel](/docs/concepts/channels/) | Receives requests and delivers replies | Receives issues assigned to Ren |

If a tool has no app but has an MCP server, add it as a [custom MCP](/docs/concepts/custom-mcps/).

## Add an app to a project

<SurfaceTabs>
<Fragment slot="app">

<Steps>

1. Open **Marketplace → Apps** and select the app.
2. Select **Add**, then pick a project.
3. If the app needs an account, sign in or enter its key. Then select **Add to** and the project name.

</Steps>

Ren attaches the MCPs and skills of the app to the project. They are ready in the next chat of the project.

## Connect an account

When Ren needs an app that is not connected, it shows a connect card in the chat. If the app is not in the project yet, a connection from the card also adds it.

<SurfaceTabs>
<Fragment slot="app">

<Steps>

1. Select **Connect** on the card in the chat.
2. Sign in to the account that you want Ren to use, or enter the key that the app asks for.
3. Go back to Ren. The card shows **Connected**, and Ren continues.

</Steps>

### Where Ren saves the connection

| Project location    | Where Ren saves the connection |
| ------------------- | ------------------------------ |
| A shared space      | The space of the project       |
| Your personal space | Your personal credentials      |

If your organization already has a connection for the app, Ren uses it. The connection dialog then shows **Connected using organization credentials**. For the full lookup order, see [Credentials](/docs/concepts/credentials/).

## Use an app in a chat

Type `@` in the composer and pick the app. The mention tells Ren which app to use for that request:

```text
@Gmail summarize my unread email from today.
```

Mentions are optional. Mention an app when more than one service can do the request. If the project does not have the app, Ren shows a connect card to add it.

When you remove an app, Ren detaches its MCPs and skills from the project. If no other project in that space needs the credentials of the app, Ren also deletes them from the space. Credentials at the organization level stay.

## Troubleshooting

### The sign-in page does not load

Some apps, such as Figma, Meta Ads, and Shopify, end the sign-in on a page that does not load. This is expected.

1. Copy the full address of that page from the browser.
2. Paste it into **Paste the address from the sign-in tab** on the card.
3. Select **Finish**.

### The connect card does not work in a channel

Connect cards work only in the web app, not in channels. Connect the account from a chat in the web app.

## Good to know

- Each space holds one connection for each app. A new connection replaces the old one.
- To use two accounts for one app, connect one in each space. Or connect one at the organization level and one in the space.
- If another space that you belong to has a connection, select **Reuse** to copy it into this space. Select **Add new** to connect a different account.
- In shared spaces, Ren uses the connection of the space before the connection of the organization. In your personal space, your personal connection comes first.
- The marketplace lists the skills of an app with the app, not under **Marketplace → Skills**.
