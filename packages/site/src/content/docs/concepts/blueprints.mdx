A blueprint is an installable Ren setup for a project, a space, or an organization. Use a blueprint when you want a ready-made setup instead of building it yourself. A blueprint can include skills, custom MCPs, instructions, an environment, and schedules.

<AskRen prompt="Install the Software Factory blueprint." />

## Blueprint types

| Blueprint                   | What it adds                         |
| --------------------------- | ------------------------------------ |
| Space blueprint             | A new shared space with its projects |
| Project blueprint           | A project in a space that you pick   |
| [App](/docs/concepts/apps/) | A single tool in a project           |

The **Software Factory** blueprint creates a space with Plan, Build, Review, QA, and Monitoring projects. Each project has instructions and skills. The projects share a machine that includes the required tools.

## Install a blueprint

Browse blueprints in **Marketplace → Blueprints** in the app. You can install space and project blueprints through Ren, the CLI, or MCP.

## What installing adds

Ren creates editable spaces and projects in your organization.

| Item                                     | What Ren does                                  |
| ---------------------------------------- | ---------------------------------------------- |
| Instructions, permissions, default model | Ren gives them to each project                 |
| Skills and custom MCPs                   | Ren attaches them to the projects              |
| Schedules                                | Ren creates them **paused**                    |
| Databases, artifacts, starter tasks      | Ren adds them where the blueprint defines them |

## Finish the setup

After the installation, Ren lists the remaining setup.

1. Connect the required accounts.
2. Add the listed [channels](/docs/concepts/channels/), such as Slack channels or GitHub repositories.
3. Turn on the schedules that you want from **Scheduled**.

## Good to know

- Schedules stay paused, so nothing runs until you turn them on.
- Installing does not overwrite existing resources. In an existing project, Ren appends the instructions of the blueprint and keeps your settings.
- Later changes to a blueprint do not update your copies. But attached skills and custom MCPs still use their latest versions.
- The public [Blueprints catalog](/blueprints) lists apps. To add an app, see "Add an app to a project" in [Apps](/docs/concepts/apps/).
