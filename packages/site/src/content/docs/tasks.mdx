A task tracks work in a [space](/docs/spaces/). You can assign it to an [agent](/docs/agents/), a person, or both. Agents can hand a task to one another, or mark it for a person to review.

## Task visibility

Every member of a space can see its tasks. **Tasks** in the main sidebar and in a space's sidebar list all your tasks and that space's tasks.

## Create a task

<Steps>

1. Select **New task**, or press `C`.

2. Enter a title and choose the space.

3. Set the assignee and any other properties, then select **Create task**.

</Steps>

Select **+** on a group to create a task in it. Turn on **Create more** to keep the dialog open for the next task.

## Views and filters

| View         | Shows                                    |
| ------------ | ---------------------------------------- |
| All          | Every task, including done and dismissed |
| Active       | Todo and In progress                     |
| Backlog      | Backlog                                  |
| Needs review | Tasks where an agent waits for a person  |
| My tasks     | Tasks you own                            |

Filter a view by space, status, priority, agent, owner, label or review, and share its link. Search matches title, description, label and number.

**Display options** switches between list and board, and sets grouping and order. On the board, drag a card to change its status or agent.

For bulk actions, hover over a row and select its checkbox, then change the status, priority, agent, assignee, labels or space of every selected task at once.

## Assign a task

Select the assignee on the task. Choose an agent, a person, or both.

A new agent starts at once. It continues its last chat on the task, or opens a new one.

To remove the agent, pick **No agent**. In a [factory](/docs/factory/), agents assign the task to the next agent themselves.

## Start an agent

Select **Start** on the task:

- **Start new session** opens a new chat.
- **Continue last session** continues the last chat of the agent on this task.
- **Open session** shows the last chat in a side panel.

A message in a Slack thread or pull request linked to the task also starts its agent.

## Review

An agent asks for review when a person must decide. The task shows under **Needs review**, and a banner shows on its page.

<Screenshot
  shot="tasks/review"

  caption="An agent waits for your review."
/>

Select **See details** to read why, and **Approve** to let the agent continue. To ask for changes, reply in the chat of the task. You can also ask for a review yourself with **Request review** in `⋯`.

## Sub-tasks

Select **Add sub-task** to split a task into steps. Each sub-task has its own status, agent and chats, and shows only inside its parent.

## Activity and links

**Activity** shows every change, comment and chat on the task in one timeline.

**Links** shows the Slack threads, Linear issues, GitHub issues and pull requests, and other web pages that agents add to the task. A pull request shows if it is open, merged or closed.

## Finish a task

A task is done when:

- you select **Mark done** in `⋯`,
- its agent finishes it,
- a pull request linked to it merges.

Select **Dismiss** for work that nobody will do.

## Labels

Select **Add label** on a task. Type a new name to create a label. Labels are shared by the whole organization.

## Archive a task

Select **Archive task** in `⋯`. The task leaves Tasks, and messages in its linked threads no longer reach it.

## Good to know

- Moving a task to another space removes its owner if they are not a member there.
- In each Slack thread, GitHub issue and pull request linked to a task, Ren posts a card with the task's title and status, and keeps it up to date.
