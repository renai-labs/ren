The [web app](https://useren.ai/app) lets you chat with Ren, attach files, and review its work in your browser. Use it to follow each step of the work, answer questions from Ren, and manage Ren.

## When to use the web app

| Use                                      | What you do                                                                                                                         |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Inspect work**                         | Expand individual steps to see the actions of Ren. Send more instructions between messages.                                         |
| **Review results**                       | Open the reports, dashboards, and files that Ren creates, next to the chat that made them.                                          |
| **Answer questions and approve actions** | Respond in the chat.                                                                                                                |
| **Manage Ren**                           | Create [spaces](/docs/concepts/spaces/) and [projects](/docs/concepts/projects/), invite teammates, connect apps, and map channels. |

## Other surfaces

| Surface                              | Use it to                                                                   |
| ------------------------------------ | --------------------------------------------------------------------------- |
| [Channels](/docs/concepts/channels/) | Send requests from team conversations. Continue those chats in the web app. |
| [CLI](/docs/surfaces/cli/)           | Manage Ren from a terminal                                                  |
| [MCP](/docs/surfaces/mcp/)           | Manage Ren from another AI tool                                             |

## Assign work

Ren can research topics, summarize data from apps, analyze files, write code, and create reports, dashboards, and pages. For example, ask Ren to turn meeting notes into a follow-up email.

| Hand off work as                        | Use it to                                    |
| --------------------------------------- | -------------------------------------------- |
| A [chat](/docs/concepts/chats/)         | Delegate a one-off request                   |
| A [task](/docs/concepts/tasks/)         | Track work that people and Ren share         |
| A [schedule](/docs/concepts/schedules/) | Repeat work on a timer, like a weekly report |

## Good to know

- [Channel](/docs/concepts/channels/) chats and [scheduled](/docs/concepts/schedules/) chats cannot ask questions. They deny actions that need approval.
- [Apps](/docs/concepts/apps/) give Ren tools.
- Files and repositories give Ren context for the work.
- You can continue a channel chat in the web app.
