# @ren/site

Docs and marketing site (Astro + Starlight).

## What belongs here

- `src/content/docs/`: documentation pages.
- Marketing pages and the API reference.

## What does not

- Product app screens (`@ren/app`).

## Dependencies

`astro`, `@astrojs/starlight`.

## Commands

```sh
bun run dev
bun run build
bun run test
bun typecheck
```
