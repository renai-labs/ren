# @ren/core

- One module per domain. Each exports `Interface`, `Service` (`Context.Service`, keyed `@ren/core/<Name>`) and `layer`. A service with distinct implementations per provider exports `layer<Provider>` instead. BrainHost shares one `layer` across celld and Cloudflare, configured by `CELL_URL`, `CELL_KEYS` and `BRAIN_MAX_FILE_SIZE`. It gets each brain's models from `Models.Service`; `Models.layerNone` grants no endpoints until a model source lands. `EnvironmentTemplates.Service` is the environment primitive: an organization's saved config for one environment provider, which spaces link through `SpaceEnvironmentTemplate`. `EnvironmentProvider.Registry` is the deployment's list of environment providers (`EnvironmentProvider.make`, one per kind; `environment-provider/docker.ts` is the first), each with a config schema that both checks the config and gives the form its JSON Schema. A provider's `provision` gets the executor's variables (`ExecutorVariables`, from `@ren/environment-api`) and sets them on the machine as they are; `connect` returns a URL where an executor answers (`EnvironmentProvider.waitForExecutor`). `provision` is idempotent per environment id: two calls for one environment give one machine, because Ren provisions outside a transaction and may ask twice. `connect` fails with `Gone` when the machine no longer exists; Ren then gives the environment's sessions a new environment and the next generation. `Environments.Service` binds a session to an environment in `session_environment`, and at the first tool call gives it an environment: one with room (`sessions_per_environment`, idle sessions not counted), or a new one the provider provisions. `release` marks a session idle (`idle_at`): it keeps its environment, and its next access clears the mark. It signs environment tokens with `ENVIRONMENT_KEYS` for `ENVIRONMENT_TOKEN_LIFETIME`.
- Name service methods with `Effect.fn("<Name>.<method>")`.
- Re-export schema values from `@ren/schema` instead of redefining them.
- Core never imports `@ren/protocol` or `@ren/server`, and never knows about Ren's own HTTP API. It calls outside services through `HttpClient` (`Mailer`), and session hosts through `@ren/host-api` (`BrainHost`).
- Tests use `testEffect(layer)` from `test/lib/effect.ts`. Use `it.live` for real time, the filesystem, child processes or the database.
- Tests run through `script/test.ts` at the repo root, with a temporary HOME and without credential env vars.
- A primitive service's `Interface` extends `Primitive.Interface<typeof <Name>.definition>`. Methods take the caller's `Actor.Info` first.
- Primitive methods fail only with `Primitive.NotFound`, `Primitive.Forbidden` or `Primitive.Conflict`. A record the actor cannot see is `NotFound`.
