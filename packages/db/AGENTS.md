# @ren/db

- Tables live in `src/<domain>.sql.ts`. Use snake_case object keys and never pass column names as strings (`org_id: text()`, not `orgID: text("org_id")`). ast-grep enforces this. The exception is `src/auth.sql.ts`, generated by the Better Auth CLI; never edit it, regenerate it with `bun run generate` in `packages/server`.
- Generate migrations with drizzle-kit (`bun run db generate`). Never edit generated migrations.
- Access Postgres through `Database.Service` (Drizzle) or `SqlClient.SqlClient`. Do not create ad hoc connections. `AuthDatabase.Service` exists only for Better Auth, which needs Promise-based Drizzle.
- Tests use `Testing.layer`, which creates a fresh database, applies migrations, and drops it when the layer's scope closes. Never point tests at a shared database. Start Postgres with `docker compose up -d` from the repo root.
- Drizzle's `execute` is typed as an array but returns `{ rows }` at runtime in the current RC. Prefer query builders or `SqlClient` for raw SQL.
